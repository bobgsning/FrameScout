# AI Policy

FrameScout is developed with the help of AI-assisted coding tools. This document explains how AI is used and who is responsible for the code.

## Human Responsibility

**I (bobgsning) take full responsibility for all code in this repository.**

Every line of code — whether written by hand or generated with AI assistance — has been reviewed, tested, and understood by me. I can explain, modify, and debug any part of the codebase without AI help.

## How AI Is Used

AI tools (Claude, ChatGPT, GitHub Copilot) assist with:

- Generating implementation code based on human-designed architecture
- Debugging and troubleshooting
- Writing documentation and comments
- Exploring alternative approaches

All architectural decisions, technology choices, algorithm designs, and quality standards are set by the human author.

## Quality Assurance

Before any AI-generated code is committed:

- It is read and understood by the author
- It is tested in the running application
- It meets the same quality standards as hand-written code
- It does not introduce third-party IP violations

## Disclosure

Contributors are encouraged but not required to mention AI assistance in their pull requests. The goal is transparency, not bureaucracy.

## Why This Matters

Transparency builds trust. Users and contributors deserve to know how this software was created. This policy reflects a commitment to honest, responsible development in an era of AI-assisted coding.
