## 二、必须做的配置改动

### 2.1 启用 `@/` 路径别名（前置条件，否则全部 import 报错）

新代码统一使用 `@/types/search`、`@/composables/useSearch` 等别名。

- `vite.config.ts`：

```ts
import { fileURLToPath, URL } from 'node:url'

export default defineConfig({
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url))
    }
  }
})
```

- `tsconfig.json` 的 `compilerOptions`：

```json
{
  "baseUrl": ".",
  "paths": { "@/*": ["src/*"] }
}
```

### 2.2 `main.ts` 引入全局样式（顺序不可颠倒：变量 → 动画 → 通用基础样式）

```ts
import { createApp } from 'vue'
import App from './App.vue'

import './styles/variables.css'
import './styles/animations.css'
import './styles/common.css'

createApp(App).mount('#app')
```

> **为何不能用组件 `<style scoped>`**：Vue 会给 scoped 里的 `@keyframes` 加哈希，跨组件复用失效；`.highlight-text` 由 `v-html` 注入，不带 scoped 选择器，必须全局。

### 2.3 备份原 `App.vue`

建议改名为 `App.vue.bak` 而非删除，便于对照回归。

## 三、重构中修复的原实现缺陷

| 位置 | 原问题 | 现在的行为 |
| --- | --- | --- |
| `useSearch.changePage` / `doJump` | 浏览模式（无搜索词）翻页走 `performSearch()`，而无查询词时它会清空结果 → **浏览模式翻第 2 页必然白屏** | 新增 `isBrowsingMode` 判定：浏览模式走 `loadBrowsePage()`，搜索模式走 `performSearch()` |
| `utils/highlight.ts` | `new RegExp(searchQuery)` 未转义，输入 `(`、`*`、`[` 抛 `SyntaxError` 卡死渲染 | 先转义正则元字符，再对原文做 HTML 转义（防 `v-html` 注入） |
| `ExtractionBus` | 进度百分比在模板里重复计算两次 | 收敛为一个 `computed` |
| `PaginationBar` | Show All 状态条嵌在 `v-if="!isShowAllMode"` 分支内，**逻辑上永远不可能显示** | 拆为两个互斥分支：Show All 模式显示状态条 + 退出按钮，否则显示常规分页器 |
| `SearchConsole` | `.visual-target-banner` 被引用但全项目无对应样式 → 以图搜图横幅裸排版 | 补齐 `.visual-target-banner` / `.target-img` / `.target-info` |
| `common.css` | `.custom-select-sm`、`.btn-text`、`.btn-outline-primary`、`.badge-timestamp` 被引用但无定义 | 全部补齐 |
| `styles/` | `:root` 变量写在 `App.vue` 非 scoped `<style>` 里，依赖组件挂载才生效 | 改为 `main.ts` 全局引入，与组件生命周期解耦 |

## 四、架构关键决策

### 4.1 模块级单例替代 Pinia

`ref` 声明在 `export function useXxx()` **外面**（模块作用域），无论 `App.vue`、`LicenseModal`、`OcrPanel`、`TopActionBar` 各自调用多少次，拿到的都是同一份状态。**无需 Pinia，无需 provide/inject。**

```ts
// useSearch.ts
const searchQuery = ref('')        // 模块作用域，非函数内
export function useSearch() { /* ... */ }
```

### 4.2 生命周期守卫防止重复订阅

`useScanner()` 会被 `App.vue` 与 `TopActionBar` 各调一次；若无守卫，`listen('scan-progress')` 会注册两次，同一条进度事件被处理两遍。每个带副作用的 composable 均加：

```ts
let lifecycleBound = false
export function useScanner() {
  if (!lifecycleBound) {
    lifecycleBound = true
    onMounted(/* 仅首次调用方注册 */)
    onUnmounted(/* ... */)
  }
  return { /* ... */ }
}
```

### 4.3 视频超时计时器提升为模块级注册表

`utils/videoTimers.ts` 作为单例：`useSearch` 发起搜索时 `armVideoTimeout()` 武装，`ResultCard` 在加载成功/失败时 `clearVideoTimer()` 解除，组件卸载时 `clearAllVideoTimers()` 兜底。

## 六、落地注意事项

- **环境变量**：`import.meta.env.DEV` 控制调试分支（如开发期直连 worker，生产期依赖 Tauri 启动的打包 worker）。
- **资产 URL**：视频/图片通过 `getAssetUrl()` + Tauri `convertFileSrc` 转为 `asset://` 协议地址，切勿直接拼接文件路径。
- **回归重点**：浏览模式翻页、以图搜图横幅、Show All 状态条、搜索特殊字符（正则元字符）、聚类阈值请求，是本次改动最易出问题的路径。
